# CRT 显像工坊

给图片一点旧时代的光。一个独立、纯静态的 CRT 图片效果工具。

**在线使用：[CRT 显像工坊](https://tito-xd.github.io/crt-image-studio/)**

## 使用

1. 打开、拖入或粘贴一张图片。
2. 选择「掌机微光」「街机时刻」「旧日电视」或「绿色终端」，再调节扫描线、荧光、点阵、弧度、暗角和颗粒。
3. 点击「对比原图」拖动分界线，或直接导出包含效果的 PNG。预览里的显示器外壳不会导出。

更多调节包含扫描线密度、色彩错位、亮度、饱和度和冷暖。图片保持原比例，不放大小图；支持原尺寸上限、2048、1080 和 720 像素最长边。

## 隐私与限制

- 图片只在浏览器内处理，不上传；没有服务端、分析统计、账户或第三方运行时请求。
- 支持 JPG、PNG、WebP 和 AVIF，格式解码取决于浏览器。单张最多 32 MB、6400 万像素。
- 输出最长边最多 4096 像素，低规格 GPU 会进一步限制尺寸；页面显示实际输出尺寸。
- 透明区域会合成为深色显像管背景，导出为不透明 PNG。
- 需要支持 WebGL 的浏览器。浏览器暂时回收绘图上下文时，会保留图片和参数并尝试恢复。
- 颗粒为静态纹理，不做闪烁动画。刷新页面会清除本次图片与参数。

## 开发

运行时无依赖，无构建步骤。需要 Python 3 启动本地静态服务器：

```sh
npm run dev
```

打开 `http://127.0.0.1:4173`。

浏览器测试需要 Node.js、已安装的 Google Chrome，以及开发依赖：

```sh
npm ci
npm test
```

测试覆盖预设与调节、重置、原图对比、上传图片的方向和像素、PNG 效果与尺寸、手机视口、拖放与粘贴、无上传请求、错误恢复和 WebGL 上下文恢复。手机视口测试不等同于实体手机验收。

验证已部署页面：

```sh
TEST_URL=https://tito-xd.github.io/crt-image-studio/ npm test
```

## 文件与发布

- `engine.js`：共享的 WebGL 滤镜，预览和导出使用同一套效果参数。
- `app.js`：导入、操作、预览、比较与导出。
- `index.html` / `style.css`：界面、响应式布局和无障碍标签。
- `assets/`：原创示例画面和图标，没有外链资源。
- `tests/`：Playwright 浏览器验收。

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 关闭 Jekyll。所有运行资源采用相对路径，可部署到仓库子路径；也可以将静态文件放到 Cloudflare Pages。

本仓库独立于 TitoDex App 和 TitoDex Launcher，不依赖它们的代码、数据或服务。
